Na Fase 5, foi solicitado a entrega da implementação do banco de dados contendo a criação de todas as tabelas da modelagem, toda estrutura de classes que pertencem ao back-end incluindo os paradigmas de POO como herança, polimorfismo e encapsulamento e como desejável o aprimoramento dos protótipos através de melhorias ou até mesmo desenvolvimento do front-end.

Nesta Fase 6, considerando a Fase 5 como pré-requisito, o grupo deverá integrar o desenvolvimento Java com Banco de Dados Oracle, obtendo assim o back-end completo, contendo:

Todas as classes necessárias para implementação do JDBC em Java.
 Camada de conexão com o BD Oracle da FIAP.
 Camada DAO.
 Implementação de métodos nas classes que permitam fazer INSERT, UPDATE, DELETE e SELECT nas tabelas do Banco de Dados.
Se necessário, manipular os dados com Collections em Java, como ArrayList por exemplo.
Ter uma classe Main que permita testar a integração com Banco de Dados em todas as classes e tabelas do BD.
 

Requisitos da entrega

Todas as classes Java devem estar em arquivos separados (1 para cada classe). Incluir todos os atributos e métodos necessários.
O arquivo .sql contendo todo Script de criação das tabelas no BD e possíveis alterações, se necessário.
